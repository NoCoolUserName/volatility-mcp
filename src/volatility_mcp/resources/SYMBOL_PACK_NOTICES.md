assets from the Volatility Foundation's `volatility3-test-data` v0.0.1 release.

included in this distribution's licenses directory and is available at

Upstream source and notices:
https://github.com/volatilityfoundation/volatility3-test-data/tree/v0.0.1

Original symbol data remains in its editable JSON/compressed-JSON format inside
the ZIP files. It is not relicensed under this project's MIT grant. The bundle
manifest records original URLs, SHA-256 hashes and the corresponding MCP source
revision. Complete MCP source, including the build script, is published at:
https://github.com/NoCoolUserName/volatility-mcp

These are representative symbol snapshots, not universal OS/build coverage.
